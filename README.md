# TLG-Naturis
A mod for Cataclysm the last generation.

The goal of this mod is to bring a little more 'life' into the convention center.


Current feautures:

Fursuit zombie spawns in citys.
Fursuit zombie variation.

Locations: 

Added fursiut zombies to the con center.

To do: 
- thematic rooms for the con center

## Installation Instructions
1. Download the src code in the latest mod release
2. Unzip the file in the 'data\mods' directory
